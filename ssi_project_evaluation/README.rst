Modul untuk menjalankan evaluasi terhadap project.project.

Fitur utama:

* Evaluasi project berdasarkan tipe evaluasi yang dikonfigurasi
* Batch evaluasi untuk banyak project sekaligus
* Pertanyaan evaluasi kualitatif dan kuantitatif
* Kalkulasi hasil evaluasi otomatis dengan Python code
* Riwayat hasil evaluasi per project per tipe
